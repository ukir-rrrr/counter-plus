# 0002 サーバーを持たず端末内で完結する

- 日付：2026-10-09
- 状態：決定

## 決定
データはすべて端末内に保存し、自前のサーバーは持たない。

## 理由
- 棚卸しは倉庫やバックヤードなど電波の弱い場所でも行う
- タップごとに通信しないので速い
- 運用費がかからず、ユーザーが少ない時期でも赤字にならない
- 個人情報を預からないので、プライバシー対応と審査が軽い

## 影響
アプリを削除するとデータが消える。機種変更はiOSのバックアップで引き継げる。将来の強化案はiCloud同期、CSVからの読み込み、チーム共有（ここでサーバーとサブスクを検討）。

- Supabase / Firebase
