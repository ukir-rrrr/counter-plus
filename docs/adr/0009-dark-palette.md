# 0009 ダークモードの配色を追加する

- 日付：2026-10-10
- 状態：決定

## 決定
`docs/design/screens.md` の色トークンにダークモードの値を追加し、端末の設定に合わせて切り替える。あわせて、accentの上の文字色として `on-accent`（ライト #FFFFFF / ダーク #0B1F1A）を追加する。項目の6色はライト・ダーク共通にする。

## 理由
要件にダークモード対応があるのに、トークンにはライトの値しかなかった。ダークのaccentは暗い背景で読めるよう明るくした（#45B497）。その上に白い文字を置くとコントラスト比が足りないため、文字色を `on-accent` として切り替える。主な組み合わせはWCAGのコントラスト比 4.5 以上を確認した（ink/surface 14.2、accent/surface 6.5、on-accent/accent 6.7、accent-ink/accent-soft 8.0）。

## 見送った案
- ダーク対応を後回しにする：トークンの仕組みを後から入れ替えると、画面ごとの直しが増える
- ダークでもaccentをライトと同じ #0F6E5C にする：暗い背景の上で文字やリンクが読みにくい
