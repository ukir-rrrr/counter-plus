# 0013 タップ音機能を外す

- 日付：2026-10-13
- 状態：決定

## 決定
タップ音（設定トグル、`expo-audio`、同梱 WAV）を外す。振動と「画面を消さない」は残す。古いインストールの `app_settings.sound` 行は読まない（未知キーは無視する）。

## 理由
実機 iPhone の Expo Go で、ワンショット再生・プレイヤープール・プリロード＋`keepAudioSessionActive` のいずれでも、タップ音が隔回だけ鳴る症状が残った。効果に見合う再現手段が無いので、機能を止める。

## 見送った案
- さらにネイティブ側で AVAudioSession を直接いじる：Expo Go では届かない
- トグルだけ残して「準備中」にする：使えない設定を残すことになる
