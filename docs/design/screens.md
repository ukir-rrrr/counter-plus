# カウンター＋ 画面仕様

> デザインの元データ：Claude Design「カウンター＋ 画面デザイン」
> https://claude.ai/artifact/6uz142ePmrGrD97bJFfrze
> 各画面のHTMLモックアップは `docs/design/mockups/`（対応表は同フォルダの README.md）。
> スクリーンショットは、このフォルダに `<画面名>.png` で追加する。

## デザイントークン

`src/constants/theme.ts` と NativeWind の設定（tailwind.config）に同じ値を定義して使う。

**項目の色（6色、ライト・ダーク共通）**：青 #3E7CB1 / 緑 #3F9A6E / オレンジ #C9772E / 紫 #9A5BB0 / 赤 #C2414B / グレー #6B726E

**文字**

- 本文：IBM Plex Sans JP（400 / 500 / 700）
- 数字：IBM Plex Mono（500 / 600）、等幅数字
- サイズ：画面タイトル 17 bold、合計 34、リストの数 22、編集シートの数 44、本文 14〜15、ラベル 12、ヒント 11

**形**

- 角丸：カード・リスト 16、ボタン・入力欄 12、シート上部 22
- タッチ領域は44pt以上。−ボタン 44×44、＋ボタン 56×44
- 余白：画面の左右 16

## ホーム（リスト）`src/app/index.tsx`

- ヘッダー：左にカテゴリ一覧ボタン、中央にカテゴリ名（タップで切り替え）、右に設定（歯車）
- 合計カード：左に「合計」と大きな数字、右に「自動保存済み」チップと項目数
- リスト：1行56pt。色の点・項目名・メモ、右端に「−（グレー）・数・＋（accent）」
- リスト末尾に「＋ 項目を追加」
- ヒント文「行を長押しで編集・並べ替え」
- ツールバー：「履歴 PRO」「CSV出力 PRO」「並べ替え」アイコン
- 最下部にバナー広告（Proなら非表示）。ツールバーとの間に余白をとる

## 項目の編集（ボトムシート）`src/app/counter/[id].tsx`

- 行の長押しで開く。右上の「完了」は閉じるだけ（自動保存）
- 数の調整：大きな数字の両側に−と＋、下に −10 / −5 / +5 / +10。数字をタップで直接入力
- 項目名・メモ（置き場所など）の入力欄
- 色：6色から選ぶ
- カテゴリ：タップで移動先を選ぶ
- 「数を0にリセット」と「この項目を削除」（赤、確認あり）
- 下部に「変更はその場で自動保存されます」

## カテゴリ一覧 `src/app/categories.tsx`

- 全カテゴリの合計とカテゴリ数
- 各行：アイコン・カテゴリ名・項目数・合計、選択中はチェック
- 「＋ カテゴリを追加」。無料版で2つ目を作ろうとしたらPRO表示と購入画面へ
- 無料版では「無料版のカテゴリは1つまでです…」の案内を表示
- 長押しで名前の変更・削除、左のつまみで並べ替え

## 設定 `src/app/settings.tsx`

- 無料版のみ、最上部に「Proにする（買い切り ¥800）」の案内
- カウント：タップ時の振動（初期オン）、画面を消さない（初期オン）
- 購入：購入を復元
- サポート：App Storeでレビューを書く、お問い合わせ、利用規約、プライバシーポリシー
- 利用規約・プライバシーポリシーはアプリ内画面（`src/app/legal/`）。お問い合わせはメール、レビューは App Store
- バージョン表示の下にビルド識別子（git 短縮ハッシュ。取れなければ unknown）

## 利用規約・プライバシーポリシー `src/app/legal/`

- 設定および Pro 購入画面のリンクから開く
- ヘッダーに戻る、本文はスクロール。トークンは他画面と同じ
- 文面の正は `src/features/legal/content.ts`。公開用の写しは `docs/legal/`。GitHub Pages（https://ukir-rrrr.github.io/counter-plus/）でホストする

## 履歴（Pro）`src/app/history.tsx`

- 右上にCSV書き出しアイコン
- 絞り込みチップ：すべて / カテゴリごと
- 日付ごとの見出し（今日 / 昨日 / 日付）
- 各行：時刻・項目名・カテゴリ・変化（+1、−1、編集、0に）のバッジ・変化後の数
- ＋は緑系、−はグレー、編集とリセットはオレンジ系のバッジ

## CSV出力（Pro）`src/app/export.tsx`

- 範囲：このカテゴリ / すべてのカテゴリ（セグメント）
- 含める列：カテゴリ名・メモ・最終更新日時（項目名と数は必ず含む）
- プレビュー：先頭数行をその場で表示。ファイル名は `counter_<カテゴリ or all>_<YYYYMMDD>.csv`
- 文字コード：UTF-8 BOM付き（Excelで文字化けしない）
- 「共有シートで送る」ボタン

## Pro購入 `src/app/paywall.tsx`

- 左上に閉じる、右上に「購入を復元」
- タイトル「カウンター＋ Pro」、サブ「棚卸しの『最後の転記』までラクにする」
- 「これまでの履歴 N件を記録中です。購入すると、すぐに見られます。」（N は count_events の件数）
- 特典5つ：CSVで書き出し / 履歴 / カテゴリ無制限 / 自動並べ替え / 広告を非表示。開いた理由（openedFrom）の行を強調
- 「無料版のまま使える機能：カウント・自動保存・項目数無制限」
- 価格「買い切り ¥800」と「サブスクではありません。追加の支払いはありません。」
- ボタン「¥800でProにする」。購入後は「Proになりました」の表示
- 最下部に利用規約・プライバシーポリシーのリンク
- 価格はRevenueCatから取得した表示用の文字列を使う（ハードコードしない）
