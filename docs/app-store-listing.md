# App Store 掲載文案とスクリーンショット計画

ステップ9の提出用ドラフトです。App Store Connect にコピーして使う。文字数は日本語（スペースなし）で数える。実際のスクリーンショット撮影と提出はオーナー作業。

## 名前・サブタイトル

| 項目 | 文案 | 上限 |
| --- | --- | --- |
| 名前 | カウンター＋ | 30文字 |
| サブタイトル | 在庫・棚卸し・回数をまとめて数える | 30文字 |

ホーム画面上の表示名は `app.json` の `name`（カウンター＋）と同じにする。ストアの長い説明は下記の説明文に書く。

## 説明文

開けばすぐ数えられて、勝手に保存され、終わったらCSVで送れる、たくさんの項目をまとめて数えるカウンターです。

小さな店や現場の棚卸し、在庫の確認、筋トレやゲームの回数など、手で数える作業に使えます。保存ボタンはありません。＋と−を項目ごとに置き、タップしたその場で数字が変わり、端末内に自動保存されます。

【こんなことができます】
・項目ごとの＋／−。0より小さくはなりません
・行を長押しして、名前・メモ・色・数値をその場で編集
・カテゴリ（棚や場所）ごとに分けて表示
・長押しで並べ替え
・数えている間は画面を消さない設定
・ダークモード対応

【無料のまま使えること】
カウント、自動保存、項目数の制限なし、カテゴリ1つ、手動の並べ替え。

【カウンター＋ Pro（買い切り）】
サブスクリプションではありません。一度買うと、そのApple IDで復元できます。
・カテゴリをいくつでも
・名前順・数の多い順などの自動並べ替え
・いつ何を数えたかの履歴
・UTF-8（BOM付き）のCSVを共有シートで送信
・バナー広告を非表示

データは端末の中に保存します。クラウドのアカウントは不要です。オフラインでもカウントできます。通信するのは広告・購入・匿名の利用計測だけです。

## スクリーンショット計画

App Store Connect で必要なサイズは時期により変わる。提出時点の「メディアマネージャ」に従う。目安（iPhone、縦向き）:

| ディスプレイ | よく使う解像度 | 必須の目安 |
| --- | --- | --- |
| 6.7 / 6.9インチ | 1290×2796 または 1320×2868 | 必須になりやすい |
| 6.1インチ | 1179×2556 | 求められることがある |
| 5.5インチ | 1242×2208 | 古い指定が残っている場合のみ |

実機またはシミュレータで、**preview または production ビルド**を使う（開発用歯車やテスト広告が出ないこと）。ライトモードを主にし、1枚はダークでもよい。

撮影する画面（この順で6枚程度）:

1. **ホーム** — 棚卸し中のリスト。合計が大きく見える。項目は「マグカップ 白」などモックの在庫名。広告は写さない（Proにするか、バナーが出る前に撮る）
2. **編集シート** — 大きな数字と ±5 / ±10、メモ欄
3. **カテゴリ一覧** — 棚ごとに分かれていること
4. **履歴** — 日付見出しと +1 / −1 のバッジ（Pro）
5. **CSV出力** — プレビューと「共有シートで送る」
6. **Pro購入** — 買い切りであること、復元があること

キャプション例（各画像の下、任意）:

1. 開けばすぐ数えられる
2. 長押しで、その場で直す
3. 棚ごとに分ける
4. いつ数えたかを残す
5. 終わったらCSVで送る
6. 買い切りのPro

使ってよい見本データ: `docs/design/mockups/` の在庫例。個人情報・実店舗の内部データは写さない。

iPad用スクリーンショットは、このアプリが iPhone のみのため不要。
