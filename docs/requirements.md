# カウンター＋ 要件定義書

## 概要

**コンセプト：開けばすぐ数えられて、勝手に保存され、終わったらCSVで送れる、たくさんの項目をまとめて数えるカウンター。**

**アプリ名：カウンター＋ - 在庫・棚卸し・回数をまとめて数える**（「＋」は全角。絵文字は使わない）

- **想定する使い方**：小さな店や現場での棚卸し・在庫数え。筋トレやゲームの回数など、個人の記録にも使える。
- **提供形態**：無料（画面下にバナー広告）と、買い切りのPro。
- **大事にすること**
  - 保存ボタンを置かず、すべて自動保存する
  - ＋と−を項目ごとに置き、モードの切り替えをなくす
  - 項目を長押しすれば、その場で編集できる
  - 数えた結果をCSVで書き出し、Excelへの転記をなくす
  - 広告はボタンから離して置き、誤タップさせない

## 無料版とPro

| 機能 | 無料 | Pro |
| --- | --- | --- |
| カウント・自動保存・項目数 | ○（無制限） | ○ |
| カテゴリ | 1つまで | 無制限 |
| 長押しで並べ替え | ○ | ○ |
| 自動並べ替え（名前順・数順） | — | ○ |
| 履歴の表示 | —（記録は行う） | ○ |
| CSV出力 | — | ○ |
| バナー広告 | 表示 | 非表示 |

## 機能要件（MVP）

| 機能 | 内容 | 提供 |
| --- | --- | --- |
| カウント | ホームはリスト表示（1行1項目）。行の右端に「−・数・＋」を並べ、＋で＋1、−で−1。モードの切り替えはなし。0未満にはしない | 無料 |
| 自動保存 | すべての変更をその場で端末に保存。保存ボタンは置かない | 無料 |
| その場で編集 | 行を長押しすると編集シートが開く。名前・数値・メモ・色・カテゴリを直せる。±5・±10ボタンと数値の直接入力あり | 無料 |
| 項目の追加・削除 | 項目数は無制限。削除は確認を出す | 無料 |
| 合計表示 | カテゴリ内の合計を画面上部に表示 | 無料 |
| リセット | 1項目、またはカテゴリ内すべてを0に戻す。取り消し可能 | 無料 |
| カテゴリ | 棚や場所ごとに項目を分ける。無料は1つ、Proは無制限 | 無料＋Pro |
| 並べ替え | 長押しで移動（無料）。名前順・数の多い順などの自動並べ替え（Pro） | 無料＋Pro |
| CSV出力 | 範囲（このカテゴリ／すべて）と列（カテゴリ名・メモ・最終更新）を選び、共有シートで送る。UTF-8 BOM付き | Pro |
| 履歴 | いつ何を数えたかを時刻つきで記録し、一覧で見る。記録は無料版でも行い、表示だけPro | Pro |
| 広告非表示 | Pro購入でバナーを消す | Pro |
| 購入の復元 | 機種変更時にProを復元する（審査で必須） | — |
| 振動・画面 | タップ時の振動を設定でオン・オフ。「画面を消さない」も設定で切り替え、数えている間は画面を点けたままにする（expo-keep-awake、初期値はオン） | 無料 |

**後回しにする機能**：ウィジェット（SwiftUIが必要）、バーコード読み取り、iCloudバックアップ・チーム共有、Android版、CSVからの読み込み

## 画面一覧と画面遷移

画面は7つ。ホームを中心に、どの画面にも1回の操作で行ける。

```
カテゴリ一覧 ←(左上ボタン)─ ホーム（リスト） ─(右上の歯車)→ 設定 ─(Proを購入)→ Pro購入
                              │
             ┌────────────────┼────────────────┐
        (行を長押し)       (メニュー)        (メニュー)
         項目の編集       履歴（Pro）      CSV出力（Pro）─(未購入)→ Pro購入
```

- 履歴とCSV出力は、未購入ならPro購入画面に進む。
- 初回起動時だけ、広告の追跡許可（ATT）の確認を出す。

## 非機能要件

| 項目 | 要件 |
| --- | --- |
| 対応端末 | まずiPhoneのみ。Androidは後回し |
| 通信 | オフラインで全機能が動く。通信するのは広告と購入（と計測）だけ |
| データ保存 | 端末内のSQLite。サーバーは持たない |
| 速さ | タップから数字が変わるまでを体感できない速さにする。保存で画面を止めない |
| 広告の配置 | バナーは画面最下部。ボタンや項目との間に余白をとり、誤タップを防ぐ |
| プライバシー | ATTを表示する。プライバシーポリシーを用意する |
| 言語 | 日本語。英語は後回し |
| 表示 | ダークモードと大きな文字に対応。数字は大きく読みやすく |
| 計測 | どの機能が使われたかを記録する（個人を特定しない） |
